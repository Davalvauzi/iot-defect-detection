01. LATAR BELAKANG

Tantangan Quality Control & Kebutuhan Otomasi

Masalah QC Manual

  • Kelelahan operator memicu *human-error*.
  • Pencatatan data manual di kertas lambat.
  • Sulit melacak tren kerusakan secara instan.

Kebutuhan Solusi

  • Inspeksi berkecepatan tinggi tanpa sentuh.
  • Keputusan lolos/cacat otomatis dlm milidetik.
  • Akses dashboard pemantauan jarak jauh.

Solusi IoT

  • Node sensor cerdas berbasis ESP32.
  • Dashboard Web & Mobile interaktif.
  • Audio alarm & pencatatan log otomatis.
Meningkatkan akurasi kendali mutu dan efisiensi pelaporan berbasis IoT.
02. TUJUAN PROYEK

4 Pilar Utama Sesuai Instruksi Tugas

1. Data Visualization

Grafik Donut (Rasio Kualitas) & Grafik Garis real-time fluktuasi sinyal sensor menggunakan Chart.js.

2. Web Dashboard

Pusat kontrol monitoring dengan kartu KPI metrik, bilik simulasi konveyor, dan ledger riwayat log.

3. Mobile Monitoring

Antarmuka responsif ramah smartphone/tablet memudahkan operator memantau jalur inspeksi di mana saja.

4. Real-Time Streaming

Streaming data instan dari mikrokontroler ESP32 via HTTP REST API JSON tanpa perlu reload halaman web.

Memenuhi seluruh capaian pembelajaran pengembangan dashboard IoT modern.

04. IMPLEMENTASI HARDWARE

Konfigurasi Rangkaian & Pinout ESP32

Opsi 1: Direct 4-Wire (Praktis)

Hanya butuh 4 kabel jumper Female-to-Female dari ESP32 langsung ke Sensor (Ultrasonik HC-SR04):

VCC ➔ Pin VIN (5V) ESP32
GND ➔ Pin GND ESP32
Trig ➔ GPIO 5 (D5) ESP32
Echo ➔ GPIO 19 (D19) ESP32

Opsi 2: Full Breadboard (Opsional)

Menambahkan aktuator & indikator fisik tambahan:

• LED Merah (Cacat) ➔ GPIO 19
• LED Hijau (Lolos) ➔ GPIO 21
• Buzzer Alarm ➔ GPIO 18
• Servo Sortir ➔ GPIO 13

Fleksibel: Bisa berjalan dengan direct wiring minimalis ataupun rangkaian breadboard lengkap.
05. TAMPILAN DASHBOARD

Antarmuka Modern & Visualisasi Interaktif

Bilik Simulasi Konveyor

Animasi pergerakan barang melintas di bawah sensor dengan indikator sinar laser (Hijau / Merah).

4 Kartu KPI Metrik

Tabel Log & Pagination

Tabel riwayat dengan pencarian cepat, filter status, dan navigasi halaman (5, 10, 25, 50, Semua baris).

07. HASIL PENGUJIAN

Validasi Respon Sistem & Analisis Kinerja

✓ Pengujian Barang Normal (Pass)

Sensor membaca nilai dalam toleransi normal. Sistem mencatat status LOLOS, counter bertambah, nada beep pendek berbunyi.

⚠ Pengujian Barang Cacat (Defect)

Sensor membaca deviasi nilai di luar ambang batas. Sistem langsung mencatat CACAT, alarm 2-nada berbunyi, servo rejector aktif.

⚡ Latensi & Kecepatan Respons

Waktu transmisi dari deteksi sensor hingga pembaruan grafik di web < 40 ms tanpa lag.

💾 Ketahanan Penyimpanan Data

Data tetap aman tersimpan saat browser direfresh atau ditutup melalui mekanisme LocalStorage.

Hasil pengujian membuktikan sistem bekerja stabil dan responsif.
