Panduan Rangkaian Hardware ESP32 & HC-SR04

Sensor Ultrasonik (HC-SR04):

VCC → VIN / 5V ESP32
GND → GND ESP32
Trig → GPIO 5 (D5)
Echo → GPIO 19 (D19)

Indikator Bawaan (Onboard):

LED Biru Bawaan Board (GPIO 2) otomatis berkedip saat mendeteksi barang cacat tanpa kabel tambahan!

Koneksi & Transmisi Data:

Streaming via kabel USB Serial Bridge (serial_bridge.py) atau WiFi HTTP POST / Firebase Realtime DB.
